# My Briefing plugin

Made from the template of [briefing-plugin-sdk](https://github.com/holtwick/briefing-plugin-sdk).

```sh
npm install
npm run check   # type-check, tests, build
npm run dev     # work on the plugin standalone
```

Rename the id `com.example.my-plugin` everywhere (`plugin-manifest.json`,
`src/_types.ts`, `package.json`). How plugins work: [AGENTS.md](AGENTS.md).
